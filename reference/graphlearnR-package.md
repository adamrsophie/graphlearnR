# graphlearnR: Graph Machine Learning and Geometric Deep Learning in R

A native R framework for machine learning on graphs, built on the
'torch' package without a Python dependency. Provides validated graph
data structures with explicit one based indexing and edge direction
semantics, conversion from 'igraph', edge lists and sparse matrices,
mini-batching of many graphs, vectorized scatter aggregation and a
general message passing interface, graph neural network layers
(GraphSAGE, GCN, GIN and GINE, GAT, GATv2, graph transformer
convolution, edge conditioned convolution, relational GCN), global and
hierarchical pooling, multi-hop neighbor sampling, leakage safe node,
edge, graph, group, scaffold and temporal splits, negative sampling,
heterogeneous graphs with typed relations and typed sampling, temporal
event graphs, snapshot sequences and spatiotemporal signals with
recurrent graph models, Graphormer style graph transformers with
structural encodings, a training loop for node, edge, link and graph
level tasks, evaluation metrics and post hoc explanations. Layer designs
follow 'PyTorch Geometric' (Fey and Lenssen 2019)
[doi:10.48550/arXiv.1903.02428](https://doi.org/10.48550/arXiv.1903.02428)
.
